# 主流模型的嵌入维度

把主流模型的嵌入维度（`config.json` 里的 `hidden_size`，论文里的 d_model）画成柱状图，
从小到大排。本书用的两个模型，SmolLM2-135M（576）和Qwen3-0.6B（1024），用深色标出来。
配合第四章「词嵌入」看。

打开 `index.html` 即可，没有构建步骤，也没有任何依赖。

## 能做什么

- **悬停**：柱子上显示机构、年份、参数量、词表大小、嵌入矩阵的形状和参数个数（词表大小 × 嵌入维度）。
- **筛选**：按机构看（全选时点一个＝只看它，之后再点＝加减）；只看稠密模型或只看MoE；
  去掉2023年以前的老模型。
- **数据表**：图下面是同样顺序的表格。

维度相同的模型按参数量排。每个维度值只在第一次出现的柱子上标数，免得满屏数字。

## 数据从哪来

大部分数字是2026-11-09从Hugging Face上各模型的 `config.json` 直接读的
（多模态模型读 `text_config`）。Transformer、GPT-1、GPT-3没有公开的 `config.json`，
数字取自原论文，表里的「来源」一栏标为「论文」。参数量是官方标称值，取整。

要加模型，在 `index.html` 里的 `DATA` 数组加一行：

```js
{name:"Qwen3-0.6B", org:"Qwen", year:2025, d:1024, vocab:151936, params:0.6, src:"config"},
```

MoE模型多写一个 `active`（激活参数，单位B）；`hi:true` 会把柱子标成深色。
