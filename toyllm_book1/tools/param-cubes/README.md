# 参数量立方体

把主流模型的参数量画成一组套在一起的立方体：体积正比于参数量，所以边长是参数量的立方根。
参数量差一千倍，边长只差十倍，135M和2.8T的模型能放进同一张图里。

打开 `index.html` 即可，没有构建步骤，也没有任何依赖。

## 怎么画的

等轴投影，所有立方体共用最靠近你的那个角，往后、往下长，小的套在大的里面。
所以每个立方体露出来的三个面上，都是一圈套一圈的正方形，最外面那圈就是最大的模型。
颜色由大到小一个色相，越小越深。

鼠标放到立方体上：

- 它的轮廓描成蓝色，右边的名字也变蓝；
- 下面的数字换成它和最小那个比：**能装下几个**（体积之比，也就是参数量之比）和**边长之比**（图上看到的）；
- MoE模型多画一个虚线立方体，是每个词元实际用到的激活参数。

眼睛比的主要是边长，所以图上的差距看起来比实际小得多。Kimi K3和SmolLM2-135M，
图上边长差27倍，参数量差20,741倍：看倍数要看下面的数字。

## 放哪些模型

上面一排是预设：本书的模型和几个大模型（默认）、2026年的大模型、GPT系列、Qwen3全系、Llama全系、
SmolLM2三个、MoE。下面是全部模型，按参数量排，点一下加进图里或拿出来。
参数量差不多的模型（7B和8B）放在一起会叠成一团，挑着放。

## 数据

和 `tools/embed-dims/` 是同一批模型，参数量是官方标称值，取整；MoE模型写成「总参数 / 激活参数」。
要加模型，在 `index.html` 里的 `DATA` 数组加一行：

```js
{name:"Qwen3-0.6B", org:"Qwen", year:2025, params:0.6, hi:true},
```

`params` 和 `active` 的单位是B（十亿）；`hi:true` 把名字加粗，留给本书用的模型。
