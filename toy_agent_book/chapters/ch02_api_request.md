# LLM API：一次请求

不用SDK，把一次API调用拆开看：发出去的是什么，收回来的是什么。

## 一个HTTP请求

### 不用SDK

只用标准库发请求，把请求和响应原样打印出来。

### 请求长什么样

地址、请求头、密钥、JSON正文。

## 消息列表

### 三种角色

消息分system、user、assistant三种角色，各是什么。

### 模型没有记忆

每次都把整段对话发回去。

## 从消息到token

服务器用对话模板把消息列表拼成一段文本，再分词。

## 请求参数

### 长度上限

模型最多说多少个token。

### 采样参数

温度、top-p、停止词，各自对应第一本采样一章的哪一步。

## 响应

### 生成的内容

### 停止原因

说完了、到上限了、要调工具。

### 用量

输入、输出、缓存各用了多少token。

## 计费和上下文窗口

### 怎么算钱

输入token、输出token、缓存token的价格。

### 上下文窗口

对话越长越贵、越慢，最后装不下。
