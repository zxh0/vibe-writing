# 提示词

到目前为止，Agent只带着一句很短的系统提示词。它能干活，但毛病不少：改完代码不跑测试，放着读文件工具不用去调`cat`，碰到问题只说话不动手。这一章用提示词把它们一条条修好。

## 写多长

一千token还是一万token，Pi和Claude Code的两种主张。

## 经典技巧还剩多少用处

写给Agent的提示词和写给聊天机器人的不一样。few-shot、思维链、角色扮演，在推理模型和训练成Coding Agent的模型上还剩多少用处。

## 措辞的分寸

全大写的“MUST”、一连串“绝不”，为什么在新模型上会矫枉过正。
