# 第 11 章　Warp 分块与流水线

> 本章要回答的问题：离 cuBLAS 只差最后一段路，剩下的差距在哪里？

## 本章目标

- 理解 block、warp、thread 三级分块结构
- 掌握双缓冲，让访存与计算重叠
- 学会用参数搜索寻找最优配置
- 与 cuBLAS 做一次完整对比

## 小节

### 11.1 三级分块

- 为什么要在 block 和 thread 之间再加一层 warp
- warp 分块对寄存器复用和调度的好处

### 11.2 双缓冲

- 载入和计算串行执行的浪费
- 两块缓冲区交替使用
- T4 上的做法：先把下一块读进寄存器，算完当前块再写进共享内存
- 异步拷贝`cp.async`要 Ampere（sm_80）以上才有，T4 上不能用，只作简述，详见第 14 章

### 11.3 调度顺序与 L2

- block 的执行顺序决定了同时在算的 block 读的是哪些 A、B 小块
- 按 swizzle 的顺序排列 block，提高 L2 命中率
- T4 的 L2 只有 4MiB，看 n=4096 时的性能下降有多少来自这里

### 11.4 自动调优

- 需要调的参数有哪些
- 搜索参数空间
- 不同矩阵尺寸下的最优参数可能不同

### 11.5 与 cuBLAS 对比

- 先弄清 cuBLAS 在 n=4096 时的异常（第 8 章记录的功耗和主频），避免得出误导的结论
- 各种规模下的对比
- 非方阵、非整数倍尺寸的对比
- 剩余差距的来源

### 11.6 第三部分回顾

- 完整的基准表
- 每一步优化解决了什么瓶颈
- 每一步优化在 roofline 上的位置
