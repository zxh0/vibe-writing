# cuda-grid

CUDA线程组织的交互演示，配合第5章“CUDA编程模型”一节使用，也可以给第6、7章当配套工具。用浏览器直接打开`index.html`即可，无需构建，也不依赖任何外部资源。

## 功能

- 设置gridDim和blockDim的x、y、z三个分量，以及要处理的数据：
  - 一维向量 c[i]，长度n，只用到x方向（y、z固定为1）
  - 二维矩阵 C[i][j]，M行N列，用到x、y方向；可以选择x对应行（第5章的朴素kernel）还是x对应列（第7章的改法）
  - 不映射数据，只看线程怎样编号、怎样分成warp，这时可以用z方向
- 三个视图，联动高亮：
  - **层次视图**：grid里排着block，block里排着线程。x向右、y向下，z方向的多层在block里从上到下排开。线程的颜色表示它属于block里的第几个warp
  - **线性化视图**：选中的block里的线程按x最快、y其次、z最慢的顺序排开，每行32个，一行就是一个warp。不足32个线程的warp，空闲的通道画成虚线
  - **数据视图**：每个元素的颜色是负责它的线程所在的warp，选中的block颜色深、其他block颜色浅。越界的线程画成虚线；grid不够大时，没有线程负责的元素会用红色斜线标出
- 点击任意一个线程、数据元素或warp的标签，三个视图会一起高亮选中的线程和它所在的warp。键盘：← / → 切换线程，↑ / ↓ 切换warp
- 右侧面板给出选中线程的blockIdx、threadIdx、block内的序号、所属warp，以及代入数字后的下标公式；还会总结选中的warp覆盖了矩阵的几行几列、写C时要访问几段互不相连的内存
- “自动算gridDim”按钮：按数据大小和blockDim算出刚好够用的gridDim
- 预设：
  - 向量加法（书中配图）：n = 30，每个block 8个线程
  - 朴素kernel，32×32：一个warp是同一列的32行
  - 朴素kernel，8×8：一个warp是8行×4列，对应第5章实测快2.7倍的那组
  - x对应列（第7章）：一个warp是同一行的32列
  - 三维block：4×4×4
  - block大小不是32的倍数：6×6，第二个warp只有4个线程
- 每个block超过1024个线程、blockDim.z超过64时给出提示，和CUDA的限制一致。线程总数或数据元素超过8192个时不再绘制
- 自动适配浅色 / 深色模式
