# gpu-arch

NVIDIA数据中心GPU的架构演进，配合第4章“GPU的整体结构”一节使用。用浏览器直接打开`index.html`即可，无需构建，也不依赖任何外部资源。

## 覆盖的架构

每一代取一颗芯片和一款数据中心产品：

| 架构 | 年份 | 芯片 | 产品 |
|---|---|---|---|
| Tesla | 2008 | GT200 | Tesla C1060 |
| Fermi | 2010 | GF100 | Tesla C2050 |
| Kepler | 2013 | GK110 | Tesla K40 |
| Maxwell | 2015 | GM200 | Tesla M40 |
| Pascal | 2016 | GP100 | Tesla P100 SXM2 |
| Volta | 2017 | GV100 | Tesla V100 SXM2 |
| Turing | 2018 | TU104 | T4（本书的实验卡） |
| Ampere | 2020 | GA100 | A100 SXM4 80GB |
| Hopper | 2022 | GH100 | H100 SXM5 |
| Blackwell | 2024 | GB100 ×2 | B200 |

## 功能

- 两种视图：
  - **SM结构**：一个SM按处理块（分区）画出，每个小方块是一个执行单元（FP32、INT32、FP64、LD/ST、SFU），紫色方块是Tensor Core，方块越宽表示单个Tensor Core的吞吐越高。下方是寄存器、L1/共享内存、Tensor Memory，条的长度按容量画
  - **整芯片**：GPC与SM的阵列、L2缓存、显存（HBM或GDDR）和对外互连。虚线框表示该产品中被屏蔽的SM或未启用的显存
- 切换架构时有补间动画：数量变化的单元平滑增减，相对上一代新增的部件以橙色描边标出，数值变化的文字变成橙色
- 右侧面板：相对上一代的主要变化、关键参数（附相对上一代的倍数）、说明和资料来源
- 底部总表：各代全部参数并排，点击表头跳到该代
- 鼠标悬停在部件上，显示它的作用
- 键盘：← / → 切换架构，Home / End 跳到第一代 / 最后一代，Tab 或 1、2 切换视图
- 导出当前图为PNG（2倍分辨率）
- 自动适配浅色 / 深色模式，也可以手动切换

## 数据

所有数据写在`index.html`开头的`GENS`数组里，每一代一个对象，改数据不需要动绘图代码。芯片级的数字（GPC、SM、每个分区的单元数）是完整芯片的配置，产品级的数字（启用的SM数、算力、显存）是该产品的规格。算力均为稠密运算的峰值。

数据来自各代的架构白皮书和产品数据手册。几点需要注意：

- “Tesla”既是第一代架构的名字，也是NVIDIA数据中心产品线的品牌，C2050到V100都属于后者。Tesla架构选的是GT200而不是更早的G80，因为GT200第一次有了FP64
- Tesla架构还没有GPC，外层是10个TPC，每个TPC 3个SM；也没有L1和L2缓存，只有纹理缓存。C1060的峰值按乘加计为622GFLOPS，官方宣传的933GFLOPS把SFU附带的乘法也算了进去
- Fermi和Kepler的执行单元由调度器共享，没有严格的分区，图中按调度器个数平均画出
- Kepler的算力按基础主频745MHz计算
- NVIDIA没有发布Blackwell数据中心芯片的完整白皮书。B200的SM内部单元数、完整芯片的SM数、L2大小、FP32和FP64算力、主频都来自第三方资料或推算，页面上以虚线下划线或“待核实”标出
- Pascal的L1/纹理缓存大小也待核实
