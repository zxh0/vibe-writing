# t4-explorer

T4的结构探索工具，配合第4章“GPU的整体结构”一节使用，也串起了第5到7章的实测数字。用浏览器直接打开`index.html`即可，无需构建，也不依赖任何外部资源。

## 层级

点击带 › 的部件进入下一层，点面包屑或按 Esc 返回。鼠标停在任意部件上，右侧显示它的说明、关键数字（规格值和书中的实测值）以及相关章节。

- **T4**：40个SM、L2、8个显存控制器和GDDR6、PCIe、主机
  - **SM**：L1指令缓存、4个处理块、L1缓存/共享内存，以及第4章配图省略的FP64单元、纹理单元、RT Core
    - **处理块**：L0指令缓存、warp调度器、寄存器文件、INT32、FP32、Tensor Core、LD/ST、SFU
      - **Warp调度器**：模拟多个warp轮流发射指令、隐藏读指令的延迟；可调warp数、延迟、两次读之间的计算指令数，显示调度器利用率
      - **寄存器文件**：拖动“每个线程的寄存器数”，看每个处理块能驻留几个warp、occupancy是多少（简化模型）
      - **FP32单元**：一个warp的32个线程分两个周期在16个FP32单元上执行
      - **Tensor Core**：4×4×4矩阵乘加，Tensor Core一个周期完成，对比16个FP32单元要4个周期
    - **L1 / 共享内存**：96KiB的两种划分、128字节缓存行与32字节sector、共享内存的32个bank

## 数据来源

规格来自NVIDIA Turing架构白皮书和T4数据手册；延迟、带宽、峰值等实测数字来自`code/ch05`和`code/ch06`的`results.txt`。调度器和寄存器两层是示意模型，不是精确的硬件行为。
