# matmul-demo

矩阵乘法演示，配合第1章“什么是矩阵乘法”一节使用。用浏览器直接打开`index.html`即可，无需构建，也不依赖任何外部资源。

## 功能

- 设置 M、K、N（1到8），即 A 为 M×K、B 为 K×N
- 元素取值：顺序整数（默认，与第1章手算的例子一致）、随机整数（-3到3）、随机整数（0到9）
- 布局：A × B = C 排成一行，顶端对齐；A 中当前用到的元素标红，B 中标绿，C 中正在更新的元素标橙
- 三种视角：
  - **点积视角**：按 i、j、k 的顺序，一次算完 C 的一个元素。勾选“逐次乘加”时每步做一次乘加，否则每步算完一个元素
  - **外积视角**：k 在最外层，每次用 A 的一列和 B 的一行更新整个 C。勾选“逐次乘加”时每步更新 C 的一个元素，否则每步加上一个完整的外积，并在下方显示这个外积
  - **分块视角**：可选块大小（1×1 到 4×4），块边界以较宽的缝表示。每步做一次小矩阵乘法 C<sub>IJ</sub> += A<sub>IL</sub>B<sub>LJ</sub>，并在下方显示两个小块、它们的乘积和累加后的结果。尺寸不能整除时，边上的块会小一些
- C 中未完成的元素显示部分和，已完成的元素变灰
- 播放 / 暂停、上一步、下一步、重置、直接算完、速度调节
- 点积视角和分块视角下，点击 C 的任意一格可直接跳到对应的步骤
- 键盘：← / → 单步，空格播放 / 暂停
- 导出：
  - **导出GIF**：把当前视角、当前参数下的整段动画（第0步到最后一步）导出为循环播放的GIF，帧间隔取当前速度，首帧和末帧多停留一会儿
  - **导出当前帧PNG**：导出当前这一步的静态图，可作为印刷版或PDF里的替代图
  - 可选“附带说明文字”，在图下方加一行当前步骤的算式
  - 导出的图片固定为浅色配色、2倍分辨率；导出完成后，页面会提示放进书里时`<img>`的`width`应写多少（像素宽度的一半）
  - GIF编码器内置在页面里，不依赖外部库；相邻帧只编码变化的区域
  - 帧数超过200时会先确认，可减小矩阵尺寸或取消“逐次乘加”来减少帧数
- 自动适配浅色 / 深色模式和手机屏幕
