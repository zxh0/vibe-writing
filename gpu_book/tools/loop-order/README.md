# loop-order

循环顺序演示，配合第2章“循环顺序”一节使用。用浏览器直接打开`index.html`即可，无需构建，也不依赖任何外部资源。

## 功能

- 六种循环顺序：ijk（点积视角）、ikj、jik、jki、kij（外积视角）、kji，默认 ikj
- 设置 M、K、N（1到6），即 A 为 M×K、B 为 K×N；元素取值可选顺序整数或随机整数（0到9）
- 上方显示当前顺序的三重循环代码，以及 i、j、k 的当前值
- 中间是 A × B = C：深色是这一步访问的元素，浅色是最内层循环这一轮会扫过的元素；C 中未完成的元素显示部分和，已完成的变灰
- 下方是三个矩阵在内存中的样子（行主序的一维数组，行与行之间留缝）：
  - 箭头从上一步访问的地址指向这一步的地址，标出相隔几个元素（`+1`、`+4`、`−3`，同一地址标“不动”）
  - 右侧统计到目前为止的“连续”（不动或+1）和“跳跃”（其余情况）次数
- 每一步做一次乘加；播放 / 暂停、上一步、下一步、重置、直接算完、速度调节
- 键盘：← / → 单步，空格播放 / 暂停
- 导出：
  - **导出GIF**：当前顺序、当前参数下的整段动画，帧间隔取当前速度
  - **导出当前帧PNG**：当前这一步的静态图
  - 可选“附带说明文字”，在图下方加当前这一步的算式，以及最内层循环的访存特点
  - 导出的图片固定为浅色配色、2倍分辨率；导出完成后，页面会提示放进书里时`<img>`的`width`应写多少
  - GIF编码器与 matmul-demo 相同，内置在页面里
- 自动适配浅色 / 深色模式
