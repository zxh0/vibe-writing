# 第 19 章　今天的 TPU，以及回头看我们的设计

> 本章要回答的问题：从第一代走到今天，TPU 变了什么、没变什么？我们的"从零设计"和 Google 的真实路径差在哪里？

## 本章目标

- 梳理 TPU 各代的关键变化和背后的驱动力
- 理解大模型推理时代对硬件的新要求
- 系统对比 TPU 与 GPU
- 回顾全书的设计决策

## 小节

### 19.1 一代代走来

- v1：推理，int8，DDR3
- v2/v3：训练，bf16，HBM，pod，液冷
- v4：3D torus，OCS，SparseCore
- v5e / v5p：分出性价比和性能两条产品线
- Trillium（v6e）与 Ironwood（v7）
- 每一代都对照"本书哪一章的哪个决策被改变了"

### 19.2 大模型推理时代

- FP8 等更低精度
- 更大的 HBM：KV cache 和超大模型
- chiplet：Ironwood 每颗芯片两个 chiplet，对编程模型的影响
- 推理又一次成为重点，回到第一代的出发点

### 19.3 TPU 与 GPU

- 同一个矩阵乘法的两种解法：专用脉动阵列 vs 通用 SIMT + Tensor Core
- 存储层次、编程模型、互连、软件生态的对比
- 两者在相互靠近：GPU 越来越专用，TPU 越来越可编程
- 与 gpu_book 的总结章互相引用

### 19.4 回到第 3 章的目标

- 我们定下的目标，有哪些实现了，有哪些在后来被推翻
- 我们的模拟器与真实芯片的差距

### 19.5 还没解决的问题

- 可编程性与效率的平衡
- 稀疏性
- 内存墙：算力增长远快于带宽增长
