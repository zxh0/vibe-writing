# 第 9 章　累加器与激活单元

> 本章要回答的问题：阵列算出的部分和放在哪里？一层算完之后，激活函数和量化由谁来做？

## 本章目标

- 理解 K 维分块后部分和的累加方式，以及为什么需要单独的累加器存储
- 理解激活、池化、重新量化在数据通路中的位置
- 让模拟器在芯片上跑完一个两层 MLP 的前向

## 小节

### 9.1 部分和放在哪

- 阵列底部每拍输出一行 32 位部分和
- 累加器：一块专门的 SRAM，按地址把新部分和加到旧值上
- 为什么不直接写回 Unified Buffer：位宽不同、需要读改写

### 9.2 K 维分块后的累加

- K 大于阵列边长时，一次矩阵乘法拆成多次，结果在累加器里加起来
- 累加器的容量决定了一次能处理多大的输出块
- 累加器也可以做双缓冲

### 9.3 激活、池化和归一化

- ReLU、sigmoid、tanh：用查表或简单电路实现
- 池化：在激活之后做
- 哪些做成固定功能硬件，哪些留给主机

### 9.4 重新量化

- 32 位累加结果乘以 scale、加偏置、截断回 int8
- 写回 Unified Buffer，作为下一层输入
- 整个过程不经过主机 CPU

## 实验

- 给模拟器加上累加器和激活单元
- 跑一个两层 MLP 的前向：输入 → 矩阵乘 → 累加 → ReLU → 量化 → 矩阵乘 → 输出，结果与 NumPy 比对
